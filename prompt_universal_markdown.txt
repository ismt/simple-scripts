Сгенерируй документ в формате чистого Markdown (CommonMark), 
который корректно отобразится в любом стандартном рендерере — 
GitHub, GitLab, PyCharm, VS Code, Obsidian, Notion при импорте.

Требования:
- Только базовый синтаксис CommonMark + минимальные GFM-расширения 
  (таблицы, зачёркивание, чекбоксы) — без специфичных для одного 
  движка фич.
- Заголовки через # ## ### (не через подчёркивание ===/---).
- Для внутренних ссылок используй автогенерируемые якоря заголовков 
  в формате GitHub: текст в нижний регистр, пробелы заменены на 
  дефисы, знаки препинания убраны. НЕ используй синтаксис {#id} 
  (Pandoc/kramdown) и НЕ используй сноски [^1] — они поддерживаются 
  не везде.
- Если нужен кастомный якорь — вставляй HTML-тег <a id="..."></a> 
  прямо перед заголовком, а не полагайся на нестандартные атрибуты.
- Код оформляй тройными обратными кавычками с указанием языка.
- Списки — через дефис "-", нумерованные — через "1.".
- Таблицы — через | с выравниванием :---:.
- Не используй HTML-таблицы, кастомные блоки-предупреждения (::: note) 
  или другие директивы конкретных статических генераторов (MkDocs, 
  Docusaurus и т.п.), если явно не попрошу.
- Проверь, что все внутренние ссылки на заголовки соответствуют 
  реальным сгенерированным id.
